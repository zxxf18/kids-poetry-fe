# kids-poetry-fe

“童诗小书房”前端。暖色绘本画风，以一本可以翻阅、检索和收藏的儿童诗册为核心体验。

## 已实现

- 关键词搜索：诗名、诗人、诗句和译文
- 独立题目/作者输入，以及朝代、诗/词、体裁、题材、词牌筛选
- 流传最广、小学精选、经典选本等快捷诗册
- 诗词详情：正文上方拼音、拼音开关、白话译文、注释和赏析切换
- 浏览器本地收藏诗笺
- 320px 起的移动端布局、触控友好控件和低高度横屏布局
- 固定部署子路径 `/poetry/`

## 本地开发

后端运行在 `127.0.0.1:8890` 时：

```bash
POETRY_API_ORIGIN=http://127.0.0.1:8890 npm run dev -- --host 127.0.0.1
npm run lint
npm run build
```

生产环境由 Nginx 将 `/poetry/api/` 转发到后端，因此构建产物不包含服务器地址或凭据。

详细交互与响应式说明见 [docs/ui-design.md](docs/ui-design.md)。
