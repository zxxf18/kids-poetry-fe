# 诗里山河：界面与交互说明

## 视觉方向

整体模拟一本温暖但不陈旧的儿童绘本：米白宣纸作为底色，陶土橘承担主要操作，低饱和杏色和青绿作为辅助。宋体用于标题与正文，系统黑体用于操作和解释，避免为了“古风”牺牲儿童阅读清晰度。

首屏插图承担情绪而不是装饰：右侧孩子读书与山水建立“在诗里看见远方”的叙事，左侧留白确保搜索任务始终清楚。页面不使用卡通气泡、彩虹渐变和过密动画，阅读体验兼顾小学低年级到高年级。

## 信息结构

1. 首屏：一句价值说明、全局搜索、常用示例和从“流传最广”中随机抽取的今日一诗。
2. 快捷诗册：流传最广、小学精选、经典选本、初识古诗和十类常见题材。
3. 找诗条件：题目、姓名、朝代、内容类型、体裁、题材、词牌。
4. 紧凑目录：每次取 24 首，按可用宽度使用 1、2、3、4 或 6 列；接近页尾时自动续页，并展示拼音/译文/注释覆盖标记。
5. 独立全文书页：可刷新、可分享、支持浏览器返回；正文与拼音优先，译文、注释和赏析作为分层阅读。

## 详情交互

- 拼音默认逐字显示；长句在移动端按字安全换行，组诗序号也补充拼音，可一键关闭。
- 白话译文、词语注释、赏析使用标签页，避免把孩子一次性淹没在长文本中。
- 收藏只保存在当前浏览器的 `localStorage`，不要求儿童注册，也不采集个人信息。
- 译文、注释、赏析入口始终可点击；字段缺失时分别给出适合孩子理解的整理中说明。
- 来源只在后端保留，不在儿童阅读页展示。

## 响应式

- 超宽屏（≥ 1900px）使用 6 列，普通桌面（1200–1899px）使用 4 列，中屏（900–1199px）使用 3 列。
- 平板（621–899px）使用 2 列，竖屏手机（≤ 620px）使用单列；24 首在所有列数下都能填满整行。
- 移动端主题诗册横向滑动时标题随内容一起移动，不覆盖后方按钮；全文按原文、译注上下连续阅读。
- 窄屏（≤ 360px）：筛选器单列，标题字号收缩，保证 320px 宽度不横向溢出。
- 低高度横屏（高度 ≤ 500px）：首屏恢复左右结构并压缩纵向留白；全文恢复左右双页，各页内容可独立纵向浏览。
- 尊重 `prefers-reduced-motion`，关闭非必要动效。
