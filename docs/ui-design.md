# 童诗小书房：界面与交互说明

## 视觉方向

整体模拟一本温暖但不陈旧的儿童绘本：米白宣纸作为底色，陶土橘承担主要操作，杏色、桂花黄和低饱和青绿区分诗卡。宋体用于标题与正文，系统黑体用于操作和解释，避免为了“古风”牺牲儿童阅读清晰度。

首屏插图承担情绪而不是装饰：右侧孩子读书与山水建立“在诗里看见远方”的叙事，左侧留白确保搜索任务始终清楚。页面不使用卡通气泡、彩虹渐变和过密动画，适读年龄可以扩展到小学高年级。

## 信息结构

1. 首屏：一句价值说明、全局搜索、常用示例和今日一诗。
2. 快捷诗册：流传最广、小学精选、经典选本和常见题材。
3. 找诗条件：题目、姓名、朝代、内容类型、体裁、题材、词牌。
4. 诗卡列表：最少信息帮助判断，点击后再展开完整阅读。
5. 诗词详情：正文与拼音优先，译文、注释、赏析作为分层阅读。

## 详情交互

- 拼音默认显示在对应整行正文上方，可一键关闭。
- 白话译文、词语注释、赏析使用标签页，避免把孩子一次性淹没在长文本中。
- 收藏只保存在当前浏览器的 `localStorage`，不要求儿童注册，也不采集个人信息。
- 数据来源固定显示在详情底部，成人监护人可以了解译注来源与授权边界。

## 响应式

- 桌面（≥ 851px）：首屏双栏，诗卡三列，筛选器单行优先。
- 平板（561–850px）：首屏上下排列，诗卡两列，筛选器两至四列。
- 竖屏手机（≤ 560px）：诗卡单列，主题诗册横向滑动；详情成为底部全宽书页，主要按钮触控高度不低于 34px。
- 窄屏（≤ 360px）：筛选器单列，标题字号收缩，保证 320px 宽度不横向溢出。
- 低高度横屏（高度 ≤ 500px）：首屏恢复左右结构并压缩纵向留白；详情限制在 96dvh 内滚动。
- 尊重 `prefers-reduced-motion`，关闭非必要动效。
